`SetJavaScriptEnabled`. React requires JavaScript. Exact navigation/permission
origins, no privileged JavaScript bridge, TLS validation and native safety gates
are implemented; that does not amount to an XSS/security certification. Existing
unit skips cover Windows ABI, absent historical/licensed fixtures and optional
dependencies; they do not imply those capabilities passed.

The initial restricted-shell suite could not start FastAPI's `TestClient`:
local socket-pair writes were denied, also reproduced with a minimal non-product
app. The full run then used approved network/IPC execution. The three browser
failures were solely the tests' expected `/opt/google/chrome/chrome` path; the
existing Cloud wrapper mounts the saved Chrome there. The actual rerun was
3 passed in 6.04 seconds. SDK/JDK/Gradle provisioning subsequently succeeded
through the supported approval path; early approval-service capacity failures
did not remain a build blocker.
