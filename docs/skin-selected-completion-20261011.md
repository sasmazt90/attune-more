## Real local training and evidence

This machine has CPU PyTorch and no CUDA GPU. Training uses two Torch CPU threads, original source crops, local pixel tensors and existing licensed pretrained weights. It does not use cached frozen ImageNet features as full fine tuning. Acceptance thresholds were frozen before the selected detector/mask runs and were not lowered.

All runs include a train-only small-set learning check, actual feature gradient/weight-change receipts, validation selection, finite epochs/wall time, cosine scheduler and transactional safe checkpoints with optimizer, Torch/NumPy/Python RNG, order/cursor and scheduler state. The small-set weights are reset before regular training. No model generates its own truth.

* **EfficientNet-B0:** 879 train / 187 development validation crops, RGB224/ImageNet camera crop preprocessing; upper features 6/7/8 plus classifier train. The eight-case learning check reached accuracy 1.0; mean loss fell from 0.9480 to 0.000007. Eleven validated epochs, best epoch 7. Macro-F1 gate 0.60 and minimum class F1 gate 0.40 fail. Required features have positive gradients and maximum weight changes 0.026155/0.025787/0.027629. The final unused four-class requirement also fails.
* **Shared small ResNet18 U-Net:** seven independent logit/sigmoid targets, never a mutually exclusive softmax. It does not use a polygon-plus-two-pixel band. Dice/IoU are reported on positive ROIs; negative-only ROIs contribute FPR, not artificial perfect Dice.
