# Real female-calm-v1 closing narration checks

These recordings use synthetic, nonpersonal facts about work pressure, sleep and helpful walks. Each was generated through the real authenticated `/api/mental/neural-speech` endpoint with speech consent and a simulated authenticated, parked vehicle. No analysis provider, private transcript or paid API was used. The ephemeral test token is excluded from all artifacts.

The [verification record](verification.json) contains exact texts, hashes, PCM metrics, response headers, conditioning/settings and pinned source/model revisions. All three recordings are mono 24 kHz PCM16, with zero clipped samples and no excessive edge silence. Both independent recognizers produced normalized exact matches. Turkish and German retain formal address.

The endpoint verified the requested `female-calm-v1` profile and locale, and used the same approved reference SHA-256 and synthesis settings as the prepared library. Descriptive comparisons with the pinned generator's voice encoder are included. That encoder is part of the generator; its uncalibrated cosines are not independent biometric identity certification. Individual owner listening approval is recorded for the original nine representative recordings and six joins; it is not attributed to these new engineering proofs.

The longer, multi-sentence fixtures exercise the existing deadline on the Cloud CPU. Live structured analysis now requests a single spoken sentence of at most 12 words and 100 characters to leave more synthesis margin, while retaining full detail in `summaryText`. The 180-second worker, proxy/client deadlines, consent/vehicle checks, cancellation and text-result preservation remain intact. No pitch/rate processing or substitute voice model was used.
