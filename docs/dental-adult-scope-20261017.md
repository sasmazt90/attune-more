# Adult dental output scope and requested title

`adult-permanent-D-only-v1`, after the original model decode, per-class NMS and
source-coordinate mapping. Only permanent-tooth `D` candidates remain in the
product list. Lowercase `d` is removed, never converted into `D`. The count,
source boxes, summary and new numeric record use that same validated list.
A valid d-only result can contain zero adult candidates; this is not a healthy
diagnosis. Unavailable quality/model output never becomes a valid empty result.

The raw detector still has class order `[D,d]`, confidence 0.35, NMS 0.45 and
the same source crop/scale/clipping and quality rules. ONNX SHA-256 remains
`eafaca8139e4447b1aa64375156aa47764affd91cf0594392b896ea78463bf03`.
The detector/model version and weight identity are retained separately from
the population-scope method suffix. No training, new source download or cloud
processing was introduced. Removing d changes product population scope, not
model accuracy.

New-response validation explicitly requires the adult policy and D-only list.

never filters, reclassifies or rewrites them. The new method suffix partitions
history comparison series from old D+d totals. Existing local records/photos,
permissions and storage schemas are not migrated or cleared.
