`preparation-tone.mp3` is a locally generated 440 Hz, 0.4 second sine tone
encoded with FFmpeg/libmp3lame. It contains no voice, provider output or personal
data. It exercises actual MP3 decoding and playing/ended events in keyless
harness preparation. It proves neither OpenAI TTS success nor speech quality.

identity replacement. The app does not ship this fixture. Test outputs clearly
identify a controlled source, never the user's photograph or clinical evidence.

passing its numerical/pose gates does not confer photographic quality acceptance.
